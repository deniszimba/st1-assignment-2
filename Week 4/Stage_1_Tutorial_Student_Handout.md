# Stage 1 Tutorial Activity - Why Software Engineering Still Matters

## Activity 1 - Think-Pair-Share

**If ChatGPT or Copilot can produce a 100-line Python application very quickly, what knowledge does a software engineer still need?**

1. Understanding the problem and what the client actually needs.
2. Programming knowledge to understand, test and fix the code.
3. Knowledge of requirements, design and testing to make sure the software works correctly.

## Activity 2 - Is This Software Engineering?

| Scenario | Programming? | Software engineering? | Why? |
|---|---|---|---|
| A - A student writes a 50-line Python calculator. | Yes | Not necessarily | It involves writing code, but it is a small individual program and may not need a full software engineering process. |
| B - A team develops a payroll system used by 5,000 employees. | Yes | Yes | It is a large system used by many people, so it needs requirements, design, testing and maintenance. |
| C - An AI assistant generates a simple appointment application from one prompt. | Yes | Not necessarily | AI can generate the code, but the requirements, testing and correctness still need to be checked. |

## Activity 3 - SmartCare Problem Analysis

### Task 1 - Identify stakeholders

| Stakeholder | What do they need? |
|---|---|
| Patients | Their details and appointments managed correctly. |
| Receptionists / clinic staff | A simple way to manage patients and appointments. |
| Practitioners | Access to their appointment information. |
| Clinic management | A system that improves the clinic's current processes. |

### Task 2 - Identify current problems

1. Patient and appointment information can be difficult to find.
2. Paper records can be lost or damaged.
3. Using spreadsheets and paper can lead to mistakes or duplicate information.
4. Managing appointments manually can be slow and inefficient.

### Task 3 - Ask client questions

1. What patient information needs to be stored?
2. What information needs to be recorded for each appointment?
3. Who should be allowed to create, change or cancel appointments?
4. Do practitioners need to view their own appointment schedules?
5. Should cancelled appointments still be kept in the system?

## Exit Question

**Write one activity that a software engineer must perform and that cannot safely be delegated entirely to AI.**

A software engineer must verify and test the software to make sure it meets the client's requirements and works correctly.

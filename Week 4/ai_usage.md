# AI Usage - Stage 1

## AI as Tutor

### Prompt used
I asked Microsoft Copilot:

"I am a first-year programming student working on a simple Python clinic appointment booking system. Can you explain how functions and lists can improve a basic program that currently stores appointment details in separate variables? Please explain it simply and act as a tutor rather than writing the whole program for me."

### What I learned
Copilot explained that lists can be used to keep multiple appointments together instead of creating separate variables for every appointment. This makes it easier to add, search and work with appointments.

It also explained that functions can be used for different tasks in the program, such as adding or displaying appointments. This reduces repeated code and makes the program easier to read and update.

### How I used the advice
I used these ideas in my SmartCare program by storing appointments in a list and using functions to book and display appointments.
